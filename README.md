# Телеграм-бот мониторинга цен Aviasales

Телеграм-бот для автоматического мониторинга цен на авиабилеты через API Aviasales. Бот отслеживает цены на выбранные маршруты и уведомляет пользователей, когда находит билеты дешевле установленного порога.

## 🚀 Возможности

- **Мониторинг цен**: Автоматическая проверка цен каждый час
- **Гибкие настройки**: Выбор маршрута, пороговой цены и периода поиска  
- **Уведомления**: Мгновенные уведомления о дешевых билетах
- **Поиск по запросу**: Поиск билетов в любое время
- **Популярные маршруты**: Встроенный справочник IATA кодов

## 📋 Требования

- Python 3.7+
- Токен Telegram бота (@BotFather)
- API токен Aviasales/Travelpayouts

## 🛠️ Установка

1. **Клонируйте или скачайте файлы проекта**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Получите необходимые токены:**

   **Telegram Bot Token:**
   - Напишите @BotFather в Telegram
   - Создайте нового бота командой `/newbot`
   - Скопируйте полученный токен

   **Aviasales API Token:**
   - Зарегистрируйтесь на https://www.travelpayouts.com/
   - Перейдите в раздел "API"
   - Скопируйте ваш API токен

4. **Настройте config.py:**
```python
# Вставьте ваши токены
TELEGRAM_BOT_TOKEN = "1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ"
AVIASALES_API_TOKEN = "your_aviasales_api_token_here"
```

5. **Запустите бота:**
```bash
python telegram_bot.py
```

## 🎯 Использование

### Основные команды

- `/start` - начать работу с ботом
- `/help` - показать справку по командам
- `/set_route MOW LED` - установить маршрут (Москва → Санкт-Петербург)
- `/set_price 10000` - установить пороговую цену (10,000 руб.)
- `/set_days 30` - установить период поиска (30 дней вперед)
- `/start_monitor` - начать мониторинг цен
- `/stop_monitor` - остановить мониторинг  
- `/search` - найти билеты прямо сейчас
- `/status` - показать текущие настройки
- `/routes` - показать популярные маршруты

### Пример настройки

1. Установите маршрут: `/set_route MOW LED`
2. Установите максимальную цену: `/set_price 8000`
3. Установите период поиска: `/set_days 45`
4. Запустите мониторинг: `/start_monitor`

Бот будет проверять цены каждый час и уведомит вас, когда найдет билеты дешевле 8,000 рублей на ближайшие 45 дней.

## 📝 Логирование

Бот ведет подробные логи в файле `bot.log`. Логи включают:
- Запуск и остановку мониторинга
- Ошибки API запросов
- Отправленные уведомления
- Системные события

## 🚨 Ограничения API

- Aviasales API имеет лимиты на количество запросов
- Данные кэшируются от 2 до 7 дней
- Цены могут быть неактуальными (проверяйте expires_at)

## 🐛 Решение проблем

**Бот не отвечает:**
- Проверьте правильность Telegram токена
- Убедитесь, что бот запущен

**Не находит билеты:**
- Проверьте правильность IATA кодов
- Убедитесь, что Aviasales API токен валидный
- Попробуйте увеличить пороговую цену

**Ошибки API:**
- Проверьте подключение к интернету
- Убедитесь, что не превышены лимиты API
